# Experiment 1 - MapReduce Word Count

**Aim:** To implement a Word Count program using MapReduce on Hadoop.

**Algorithm:** Read lines, tokenize words, emit `(word,1)`, group by word, sum values, and output the word frequency.

**Sample Output**
```text
hadoop 2
hello 2
mapreduce 1
world 2
```

**Result:** The Word Count program successfully counted the frequency of each word.
